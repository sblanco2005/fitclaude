# Workout System

## Overview
Workouts are generated by the AI coach based on user goals, equipment, and history. Users can view workout history, track progressive overload, and mark workouts complete with fatigue ratings.

## Workout Types
- `push` — chest, shoulders, triceps
- `pull` — back, biceps
- `legs` — quads, hamstrings, glutes, calves
- `upper` — chest, back, shoulders, arms
- `lower` — quads, hamstrings, glutes, calves
- `full_body` — all major muscle groups
- `cardio` — conditioning, HIIT, steady state
- `custom` — user-specified focus

## Generation Flow
1. User requests workout via chat ("Build me a leg day")
2. Coach calls `generate_workout` tool with type + parameters
3. Tool creates Workout record in DB
4. Coach uses user's equipment, history, and goals to select 4-7 exercises
5. Coach presents workout in clean format:
   ```
   1. Barbell Back Squat — 4x6 @ 100kg (rest 3 min)
   2. Romanian Deadlift — 3x10 @ 70kg (rest 2 min)
   3. Walking Lunges — 3x12 each leg (rest 90 sec)
   ...
   ```
6. User can request adjustments ("swap #3 for something spicier")

## Progressive Overload
- Coach checks `get_workout_history` (last 14 days) before generating
- Compares previous weights, sets, reps for same workout type
- Suggests incremental increases: +2.5kg, +1 rep, or +1 set
- Tracks trends across sessions

## Completion Flow
1. User says "Done with today's workout" or "Finished, that was brutal"
2. Coach calls `mark_workout_complete` with:
   - `workout_id` — which workout
   - `fatigue_rating` — 1 (easy) to 10 (destroyed)
   - `notes` — optional post-workout comments
3. Coach acknowledges and encourages

## Fatigue Tracking
- Fatigue ratings stored per workout (1-10 scale)
- If average of last 3 workouts is 7+, coach suggests deload week
- Visual indicator in workout history (color-coded)

## Workout Data Model
```
Workout
  ├── id, userId, date, name, workoutType
  ├── durationMinutes, notes, fatigueRating, completed
  └── exercises: WorkoutExercise[]
        ├── exerciseId, variationId, order
        ├── sets, reps, weightKg, restSeconds
        ├── notes, wasSpicy
        └── exercise: Exercise (name, muscleGroup, etc.)
```

## Workout History Page
- List view of past workouts (last 90 days)
- Each workout is an expandable card showing:
  - Workout name and date
  - Status badge: Completed / Planned
  - Fatigue rating (if completed)
  - Exercise list with sets x reps x weight
  - Spicy indicator on variation exercises
  - Notes (if any)
- Filter controls:
  - Workout type dropdown
  - Date range picker
  - Completed/all toggle

## Mobile UX
- Workout cards are touch-friendly, tap to expand
- Swipe actions: swipe right to mark complete (shortcut)
- Fatigue rating: large tap targets (1-10 buttons or slider)
- Exercise list scrolls within card if many exercises
